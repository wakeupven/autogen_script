# autogen_script — Генератор синтетического датасета 2D планов помещений

Генерирует ~50 000 синтетических 2D-планов помещений в стиле ГОСТ с масками семантической сегментации (6 классов + фон).

## Установка

```bash
pip install shapely pillow tqdm
```

## Использование

```bash
python generate_dataset.py [-n КОЛИЧЕСТВО] [-o ДИРЕКТОРИЯ] [--seed ЧИСЛО]
```

### Аргументы

| Аргумент | По умолчанию | Описание |
|---|---|---|
| `-n`, `--num-images` | 10 | Количество изображений |
| `-o`, `--output-dir` | `dataset` | Директория вывода |
| `--seed` | (случайно) | Сид для воспроизводимости |

### Примеры

```bash
# 50000 изображений
python generate_dataset.py -n 50000

# В свою директорию
python generate_dataset.py -n 1000 -o my_dataset

# Воспроизводимый запуск
python generate_dataset.py -n 100 --seed 42
```

## Структура вывода

```
dataset/
├── images/
│   ├── plan_000000.png
│   ├── plan_000001.png
│   └── ...
└── masks/
    ├── mask_000000.png
    ├── mask_000001.png
    └── ...
```

При повторном запуске нумерация продолжается с последнего существующего индекса (файлы не перезаписываются).

## Цвета маски (семантическая сегментация)

| Класс | Цвет (R,G,B) | Описание |
|---|---|---|
| M_ROOM | (0, 255, 255) | Помещение (заливка) |
| M_WALL | (255, 255, 0) | Стена |
| M_DOOR | (255, 127, 80) | Створка двери (линия + дуга) |
| M_DOORW | (128, 0, 128) | Дверной проём (прямоугольник) |
| M_WIND | (255, 0, 0) | Окно (поперечная линия) |
| M_WINDW | (255, 105, 180) | Оконный проём (прямоугольник) |
| BG | (0, 0, 0) | Фон |

## Как это работает

### Генерация комнат
- Холст: 1000–5000 px
- Комнаты: 1–4 (разбиение bounding box)
- Зазоры между комнатами образуют стены

### Стены
- Единый полигон стен через `shapely.buffer(join_style=2)` — gapless углы
- Толщина: 12–40 px
- Внешний буфер `union.buffer(wall_t)` → разность `outer.difference(union)`
- **Наклонные стены**: ~45% планов содержат непрямоугольные комнаты с V-образными наклонными внутренними стенами (смещение середины общей стены смежных комнат). Внешние стены всегда прямые.

### Проёмы (двери и окна)
- Размещаются на стенах со случайной позицией
- Проверка пересечений через `shapely.distance`
- Ширина двери: 80–120 px, окна: 100–250 px

### УГО двери
- Линия створки: от края проёма (петля), строго под 90° к стене, длина = ширина проёма
- Дуга 90°: от второго края проёма до конца линии створки
- Направление: случайно наружу или внутрь помещения

### УГО окна
- Две параллельные линии поперёк проёма
- Случайное смещение по глубине стены (параметр `WINDOW_SHIFT_RANGE`)

### Наклонные стены (не под 90°)
- После генерации BSP-разбиения ~45% комнат получают наклонную внутреннюю стену (V-образный излом)
- Излом: смещение середины общей стены двух смежных комнат навстречу друг другу (8–25% длины стены)
- Толщина стены сохраняется равномерной по всей длине
- Валидация: только простые (несамопересекающиеся) полигоны с положительной площадью
- Внешние стены всегда прямые (скосы/шамферы отключены)

### Рендеринг
- Порядок рисования: комнаты → стены (buffer) → перерисовка комнат → проёмы → обводки → повторный вырез проёмов → УГО
- PIL `ImageDraw` для растеризации

## Настройка параметров

Константы в начале `generate_dataset.py`:

- `MIN_CANVAS` / `MAX_CANVAS` — размер холста
- `WALL_T_MIN` / `WALL_T_MAX` — толщина стен
- `DOOR_W_MIN` / `DOOR_W_MAX` — ширина дверей
- `WIND_W_MIN` / `WIND_W_MAX` — ширина окон
- `MIN_ROOMS` / `MAX_ROOMS` — количество комнат
- `MIN_OPENINGS` / `MAX_OPENINGS` — количество проёмов
- `CANVAS_MARGIN` — отступ от края холста
- `WINDOW_SHIFT_RANGE` — диапазон смещения УГО окна по глубине стены
- `DOOR_LINE_DIV` — делитель толщины стены для толщины линии УГО двери
- `WINDOW_LINE_DIV` — делитель толщины стены для толщины линии УГО окна
- `WALL_FILL_RANGE` — диапазон яркости заливки стен
- `ANGLED_WALL_FRACTION` — доля комнат с наклонными стенами (0.45 = 45%)

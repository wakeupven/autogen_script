# Генератор синтетического датасета 2D планов помещений

Генерирует ~50 000 синтетических 2D-планов помещений в стиле ГОСТ с масками семантической сегментации (6 классов + фон).

## Установка

```bash
pip install shapely pillow tqdm
```

## Использование

```bash
python generate_dataset.py [-n КОЛИЧЕСТВО] [-o ДИРЕКТОРИЯ] [--seed ЧИСЛО]
```

### Аргументы

| Аргумент | По умолчанию | Описание |
|---|---|---|
| `-n`, `--num-images` | 10 | Количество изображений |
| `-o`, `--output-dir` | `dataset` | Директория вывода |
| `--seed` | (случайно) | Сид для воспроизводимости |

### Примеры

```bash
# 50000 изображений
python generate_dataset.py -n 50000

# В自定义 директорию
python generate_dataset.py -n 1000 -o my_dataset

# Воспроизводимый запуск
python generate_dataset.py -n 100 --seed 42
```

## Структура вывода

```
dataset/
├── images/
│   ├── plan_000000.png
│   ├── plan_000001.png
│   └── ...
└── masks/
    ├── mask_000000.png
    ├── mask_000001.png
    └── ...
```

При повторном запуске нумерация продолжается с последнего существующего индекса (файлы не перезаписываются). К имени файла добавляется суффикс выбранных аугментаций (например `plan_000005_LowLightNoise_Brightness_Jpeg.png`).

## Цвета маски (семантическая сегментация)

| Класс | Цвет (R,G,B) | Описание |
|---|---|---|
| `M_ROOM` | (0, 255, 255) | Помещение (заливка) |
| `M_WALL` | (255, 255, 0) | Стена |
| `M_DOOR` | (255, 127, 80) | Створка двери (линия + дуга) |
| `M_DOORW` | (128, 0, 128) | Дверной проём (прямоугольник) |
| `M_WIND` | (255, 0, 0) | Окно (поперечная линия) |
| `M_WINDW` | (255, 105, 180) | Оконный проём (прямоугольник) |
| `M_DIM` | (255, 255, 255) | Размерные линии и текст |
| BG | (0, 0, 0) | Фон |

## Как это работает

### Генерация комнат
- Холст: 1000–5000 px
- Комнаты: 1–4 (разбиение bounding box)
- Зазоры между комнатами образуют стены

### Стены
- Единый полигон стен через `shapely.buffer(join_style=2)` — gapless углы
- Толщина: 12–40 px
- Внешний буфер `union.buffer(wall_t)` → разность `outer.difference(union)`

### Проёмы (двери и окна)
- Размещаются на стенах со случайной позицией
- Проверка пересечений через `shapely.distance`
- Ширина двери: 80–120 px, окна: 100–250 px

### УГО двери
- Линия створки: от края проёма (петля), строго под 90° к стене, длина = ширина проёма
- Дуга 90°: от второго края проёма до конца линии створки
- Направление: случайно наружу или внутрь помещения
- Направление створки сохраняется для механизма коллинеарных стен

### УГО окна
- Две параллельные линии поперёк проёма
- Случайное смещение по глубине стены (параметр `WINDOW_SHIFT_RANGE`)

### Размеры стен
- Для каждой внешней стены рисуются выносные и размерная линия с засечками под 45°
- Текст длины стены (в мм) повёрнут вдоль размерной линии; для вертикальных стен — CW 90°
- **Коллинеарные стены**: если несколько стен на одной прямой, размерная линия смещается
  наружу, чтобы крайняя стена определяла основную длину, а внутренние получают
  дополнительное смещение через `compute_extra_offset_map`
- **Дверная ширина в размерах**: если к стене примыкает дверной проём,
  размерная линия дополнительно отодвигается на `max(0, dw + margin - wall_t/2 - DIM_OFFSET)`,
  чтобы створка двери не перекрывала размерный текст
- В маске (`M_DIM`) размеры рисуются белым цветом

### Аугментации (augraphy)
Применяются с вероятностью 90%:
- **Scribbles** (30%) — рукописные пометки на плане
- **Handwriting** (60%) — рукописный текст поверх плана
- **Brightness**, **LowLightNoise**, **Dithering**, **Jpeg**, **Folding**, **ColorPaper**, **DirtyScreen**, **DirtyDrum**, **InkBleed**, **SubtleNoise**

### Дубликаты стен
- После генерации стены проверяются на дублирование (одинаковые середины) — дубликаты удаляются

### Рендеринг
- Порядок рисования: комнаты → стены (buffer) → перерисовка комнат → проёмы → обводки → повторный вырез проёмов → УГО → размеры → scribbles
- PIL `ImageDraw` для растеризации

## Настройка параметров

Константы в начале `generate_dataset.py`:

| Константа | По умолчанию | Описание |
|---|---|---|
| `MIN_CANVAS` / `MAX_CANVAS` | 1000 / 5000 | Размер холста |
| `WALL_T_MIN` / `WALL_T_MAX` | 12 / 40 | Толщина стен (px) |
| `DOOR_W_MIN` / `DOOR_W_MAX` | 80 / 120 | Ширина дверей (px) |
| `WIND_W_MIN` / `WIND_W_MAX` | 100 / 250 | Ширина окон (px) |
| `MIN_ROOMS` / `MAX_ROOMS` | 1 / 4 | Количество комнат |
| `MIN_OPENINGS` / `MAX_OPENINGS` | 1 / 6 | Количество проёмов |
| `CANVAS_MARGIN` | 50 | Отступ от края холста (px) |
| `WINDOW_SHIFT_RANGE` | -0.3 / 0.3 | Диапазон смещения УГО окна (доля от wall_t) |
| `DOOR_LINE_DIV` | 8 | Делитель толщины стены для толщины линии УГО двери |
| `WINDOW_LINE_DIV` | 6 | Делитель толщины стены для толщины линии УГО окна |
| `WALL_FILL_RANGE` | (180, 210) | Диапазон яркости заливки стен |
| `DIM_OFFSET` | 50 | Базовый отступ размерной линии от стены (px) |
| `DIM_TICK_SIZE` | 6 | Длина засечки на размерной линии (px) |
| `DOOR_DIM_EXTRA_MARGIN` | 20 | Дополнительный отступ размерной линии при наличии двери (px) |
| `SCALE_MM_PER_PX` | 10 | Коэффициент перевода пикселей в миллиметры |
